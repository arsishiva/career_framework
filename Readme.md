# Wise Analytics Career Framework

This application is a comprehensive web interface designed to help analysts at Wise navigate their career progression, understand role expectations, track skills development, and view regional salary bands.

## Features
- **Career Map Explorer**: Detailed breakdown of responsibilities and dimensions for all levels (IC1-AL3).
- **Expectations & Examples**: In-depth view of skills and dimensions with concrete examples for each level.
- **Salary Bands**: Transparency into regional salary expectations for different roles.
- **Matrix View**: A consolidated matrix of the career framework.

## Getting Started
To run this application locally:

1. Create a virtual environment:
   `python -m venv .venv`

2. Activate the virtual environment:
   `.venv\Scripts\activate`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the Streamlit app:
   `.venv\Scripts\python -m streamlit run streamlit_app.py`
